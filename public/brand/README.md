# Login brand assets

- `apple.svg`: Apple logomark from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/apple.svg). See Apple's [Sign in with Apple guidance](https://developer.apple.com/design/human-interface-guidelines/sign-in-with-apple/).
- `google-g.png`: Google G mark from Google's [Sign in with Google assets](https://developers.google.com/static/identity/images/g-logo.png). See the [Google branding guidelines](https://developers.google.com/identity/branding-guidelines).
